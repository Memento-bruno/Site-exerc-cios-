# Rumo aos 5 km

Web app de treino pessoal (PWA, pt-BR) para um plano de 24 semanas: correr 5 km em menos de 30 minutos, ganhar força, melhorar a postura e reduzir dores.

Em construção. Documentação completa ao final do projeto.

## Rodar localmente

```bash
npm install
npm run dev
```

Outros comandos: `npm run build`, `npm test`, `npm run lint`.
